## 15. Risks & mitigations

| # | Risk | Likelihood / impact | Mitigation | Owner |
|---|---|---|---|---|
| 1 | **Install fails / environments drift** (wrong Python, 32-bit Python, `numpy 2` pulled in, `opencv-python` + contrib conflict, untested newer MediaPipe packaging, **unpinned transitive deps** such as `jax`/`jaxlib` resolving differently per person or per day) | Medium / High | Exact direct pins ([Section 3.1](interfaces.md#31-requirementstxt-and-requirementslock)). **Everyone installs from `requirements.lock`** (full `pip freeze`). The lock is verified on clean 3.12 venvs on **Windows and macOS** in Iteration 1, with environment markers if a platform needs a different version. Iteration 1 exit criterion requires everyone to run MediaPipe. README lists the `struct.calcsize('P')*8 == 64` check. Never install `opencv-python`. `--camera mock` lets work continue on a broken machine meanwhile. | Lead |
| 2 | **Fist vs V-sign confusion** (two folded fingers look similar edge-on or at `far` distance) | High / High | Record tilt/angle variations ([Section 7.1](data-eval.md#71-labels-and-what-to-record)); `far` condition in training; confidence threshold + smoothing absorb flicker; confusion-matrix analysis identifies it early (Iteration 3). Fallback: more targeted **train-user** samples, try `MP_MODEL_COMPLEXITY=1`. | Siri, Shobita |
| 3 | **Poor lighting** → MediaPipe misses the hand, landmarks are noisy, **camera FPS drops to ~15** | High / Medium | `dim` in the core conditions. Threaded camera so the game still renders at 60 FPS. Smoothing window in **seconds** with a min-frames guard, so the response stays ≈ 150–200 ms at 15 FPS ([Section 6.2](game-logic.md#62-smoothing-gesturesmoother-evan)). Low-FPS warning on the HUD. No-hand auto-pause makes failure *safe* rather than deadly. [Nice] detection rate per lighting ([Section 8.4](data-eval.md#84-robustness-lighting-distance-users)). Advise players to face a light source. | Triet, Evan |
| 4 | **Latency too high** (> 400 ms p95) | Medium / High | Camera capture runs in a background thread **by default** and the worker always processes the newest frame, so stale frames never queue up. `MP_MODEL_COMPLEXITY=0`, 640×480 frames, one hand only; SVM predict < 2 ms. If smoothing dominates, reduce `SMOOTHING_WINDOW_S` 0.25 → 0.18 s ([Nice] stage-level timing shows where the time goes). | Evan, Triet |
| 5 | **False triggers from random poses / transitions** | High / Medium | Trained `none` class with varied poses incl. transitions; `CONFIDENCE_THRESHOLD`; time-window majority smoothing with hysteresis; debounce + cooldown; [Nice] false-trigger rate measured ([Section 8.2](data-eval.md#82-live-action-accuracy-evan-nice)). | Siri, Evan |
| 6 | **Overfitting to team members / data leakage**, so reported accuracy is too optimistic | Medium / High | **User-based split**: 2 test users held out entirely, never used for tuning, threshold choice or training. Validation is LOUO over train users only. `make_splits`/`load_splits` reject any user or session in two splits. `evaluate.py` refuses a model trained on a test user. The shipped model is exactly the evaluated one. | Shobita, Siri |
| 7 | **Test set too small** (2 users → noisy accuracy estimate) | High / Medium | Report per-test-user numbers **and** the spread of LOUO validation scores over the 4 train users, so the variance is visible. [Nice] outside volunteers go to the test set. Slides state the sample size. | Siri, Shobita |
| 8 | **Train/live feature mismatch** (different preprocessing paths) | Low / High | Single `preprocess()`; CSV stores raw landmarks; `PREPROCESS_VERSION` stored in the model bundle and checked on load; `row_to_landmarks` round-trip test. | Triet, Siri |
| 9 | **Critical path slips** (Triet's tracking late → no recording tool → no data → no model) | Medium / High | Triet merges `Camera`/`HandTracker`/`preprocess` first in Iteration 2. Shobita builds and tests the pure recording/cleaning/split logic on sample data in parallel. Sample data from Iteration 1 unblocks Siri. The mock classifier unblocks Evan. The Lead tracks the four critical links daily. | Lead |
| 10 | **Uy overloaded** (whole game = old Parts 2 + 3) | Medium / Medium | Keyboard-first build order (gameplay → states → controller → UI). End-of-Iteration-2 checkpoint: if behind, the Lead takes the overlays and Triet the HUD in `ui.py` ([Section 10](workflow.md#10-per-person-task-breakdown)). Gameplay polish is [Nice]. | Lead, Uy |
| 11 | **Threading bugs** (races, deadlocks, a crashed worker freezing the game) | Medium / High | Strict thread rules ([Section 2.1](DESIGN.md#21-component-diagram), rule 7): Pygame/`GameController` only on the main thread, MediaPipe only on the worker thread. Communication only through locked latest-value slots and a `queue.Queue`. The worker stores exceptions in `error`, and `main.py` exits cleanly. Thread tests with join timeouts ([Section 9](workflow.md#9-testing-plan)). | Evan, Triet |
| 12 | **Merge conflicts at integration** | Medium / Medium | Strict file ownership ([Section 3](interfaces.md#3-repository-structure)); frozen interfaces; small frequent PRs; rebase daily; the Lead merges in dependency order. | Lead |
| 13 | **`main` not actually protected** (branch protection unavailable on a private Free-plan repo) | Medium / Medium | Apply for GitHub Education in Iteration 1 (Pro/Team are free for students). Until then, the merge-only-via-reviewed-PR rule is enforced by agreement, plus the Lead's daily `git log main` check. [Nice] CI runs `pytest` on every PR. | Lead |
| 14 | **Webcam differences across laptops** (resolution, FPS, index) | Medium / Low | `Camera` resizes to 640×480; `CAMERA_INDEX` configurable; camera FPS shown on the HUD and logged. | Triet |
| 15 | **Unfair game** (impossible obstacle rows, instant hit after resume) | Low / Medium | Max 2 obstacles per row; `SPAWN_GAP_PX` invariant tested; countdown + grace period. | Uy |
| 16 | **Privacy concern** with recorded data | Low / High | Landmarks only, anonymous IDs, consent, deletion on request ([Section 7.4](data-eval.md#74-files-naming-privacy)). | Shobita, Lead |
